# 评估模型中的指标

## 核心开发者留存

核心开发者留存模型关注核心开发者持续参与社区贡献的情况，是评估社区人才维系能力的关键指标。

### 组织代码核心开发者（含管理者）留存率

- 定义：统计周期内组织代码核心贡献者（含管理者）中持续保持核心身份的比率。
- 权重：25%
- 阈值：1（100%）

组织代码核心开发者留存率反映了组织对核心开发者的维系能力。该指标统计上一周期为核心且本周期仍为核心的组织代码贡献者占上一周期核心总数的比例。高留存率意味着组织能够持续投入资源支持开发者参与项目，保持项目的技术连续性和稳定性。

### 组织Issue核心开发者（含管理者）留存率

- 定义：统计周期内组织 Issue 核心贡献者（含管理者）中持续保持核心身份的比率。
- 权重：25%
- 阈值：1（100%）

组织Issue核心开发者留存率反映了组织在社区管理和沟通方面的持续投入。该指标统计上一周期为核心且本周期仍为核心的组织 Issue 贡献者占上一周期核心总数的比例。这些开发者的留存保证了社区问题的持续跟踪和有效解决。

### 个人代码核心开发者（含管理者）留存率

- 定义：统计周期内个人代码核心贡献者（含管理者）中持续保持核心身份的比率。
- 权重：25%
- 阈值：1（100%）

个人代码核心开发者留存率反映了社区对个人贡献者的吸引力和维系能力。该指标统计上一周期为核心且本周期仍为核心的个人代码贡献者占上一周期核心总数的比例。高留存率意味着社区能够为个人开发者提供良好的贡献环境和成长机会。

### 个人Issue核心开发者（含管理者）留存率

- 定义：统计周期内个人 Issue 核心贡献者（含管理者）中持续保持核心身份的比率。
- 权重：25%
- 阈值：1（100%）

个人Issue核心开发者留存率反映了社区在社区管理和沟通方面的持续吸引力。该指标统计上一周期为核心且本周期仍为核心的个人 Issue 贡献者占上一周期核心总数的比例。这些开发者的留存保证了社区沟通的连续性和问题处理的有效性。

## 核心开发者淡出

核心开发者淡出模型关注核心开发者从核心层降级为常客或访客的情况，反映社区人才流动的健康程度。

### 组织代码核心开发者（含管理者）淡出率

- 定义：统计周期内组织代码核心贡献者（含管理者）从核心层降级为常客或访客的比率。
- 权重：25%
- 阈值：1（100%）

组织代码核心开发者淡出率反映了组织在人才梯队建设方面的挑战。该指标统计上一周期为核心但本周期降级为常客或访客的组织代码贡献者占上一周期核心总数的比例。适度的淡出率是正常的人才流动，但过高的淡出率可能意味着组织支持不足或项目吸引力下降。

### 组织Issue核心开发者（含管理者）淡出率

- 定义：统计周期内组织 Issue 核心贡献者（含管理者）从核心层降级为常客或访客的比率。
- 权重：25%
- 阈值：1（100%）

组织Issue核心开发者淡出率反映了组织在社区管理人才方面的流动情况。该指标统计上一周期为核心但本周期降级为常客或访客的组织 Issue 贡献者占上一周期核心总数的比例。淡出可能是因为项目阶段变化、组织战略调整或个人发展需求。

### 个人代码核心开发者（含管理者）淡出率

- 定义：统计周期内个人代码核心贡献者（含管理者）从核心层降级为常客或访客的比率。

- 阈值：1（100%）

个人代码核心开发者淡出率反映了社区在维系个人贡献者方面的挑战。该指标统计上一周期为核心但本周期降级为常客或访客的个人代码贡献者占上一周期核心总数的比例。淡出可能是因为个人时间精力限制、兴趣转移或社区环境变化。

个人Issue核心开发者淡出率反映了社区在维系社区管理人才方面的挑战。该指标统计上一周期为核心但本周期降级为常客或访客的个人 Issue 贡献者占上一周期核心总数的比例。

# 评估模型算法

## 权重

各指标权重采用均分方式分配。

### 核心开发者留存

4个指标采用均分方式分配，每个指标权重为 25%。

### 核心开发者淡出

4个指标采用均分方式分配，每个指标权重为 25%。

### 核心开发者流失

4个指标采用均分方式分配，每个指标权重为 25%。

## 阈值

我们选择的阈值是基于不同类型开源项目的大数据观测。
